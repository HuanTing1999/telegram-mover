# 许可原文

`dependencies/` 由 `scripts/collect_licenses.py` 从当前虚拟环境的已安装发行包复制，未改写原文；`inventory.json` 记录包版本和所复制文本的 SHA-256。Python 许可复制自构建解释器的 `LICENSE.txt`，包含该发行版附带的说明。

`qt/LGPL-3.0-only.txt` 与 `qt/GPL-3.0-only.txt` 来自 GNU 官方许可文本；LGPL 第3版是在 GPL 第3版基础上的附加条款，两份均保留。

- [GNU LGPL 第3版](https://www.gnu.org/licenses/lgpl-3.0.txt)
- [GNU GPL 第3版](https://www.gnu.org/licenses/gpl-3.0.txt)
- [Qt for Python 许可与组件说明](https://doc.qt.io/qtforpython-6/licenses.html)
- [本项目第三方声明](../THIRD_PARTY_NOTICES.md)

这些第三方文本适用各自许可，不受本项目原创代码的 MIT 许可替代。
